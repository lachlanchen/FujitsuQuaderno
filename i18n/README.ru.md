# Fujitsu Quaderno

*Исследовательские заметки и легкие инструменты для Fujitsu Quaderno Digital Paper.*

Репозиторий собирает карту поколений Quaderno, исследования jailbreak и
firmware, официальные ссылки Fujitsu на firmware и практические инструменты
для управления документами. Текущий локальный контекст: Quaderno A4 Gen 2
`FMVDP41`, управляемый через обычный спаренный Digital Paper API, без root и ADB.

## Содержание

- `research.md`: поколения, ссылки на исследования и локальные заметки.
- `firmware-download-links.md`: официальные пакеты firmware.
- `tools/README.md`: заметки по macOS launcher для монтирования.
- `tools/quaderno-mount.sh`: легкий helper для монтирования.
