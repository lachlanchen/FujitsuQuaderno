# Fujitsu Quaderno

*Notas de investigacion y herramientas ligeras para dispositivos Fujitsu Quaderno Digital Paper.*

Este repositorio recopila el mapa de generaciones, investigacion de jailbreak y
firmware, enlaces oficiales de firmware de Fujitsu y herramientas practicas de
gestion de documentos. El contexto local actual es un Quaderno A4 Gen 2
`FMVDP41`, controlado mediante la API Digital Paper normal tras el emparejado,
no mediante root ni ADB.

## Contenido

- `research.md`: mapa de generaciones, enlaces y notas locales.
- `firmware-download-links.md`: paquetes oficiales de firmware.
- `tools/README.md`: notas del lanzador de montaje en macOS.
- `tools/quaderno-mount.sh`: ayuda ligera para montar el dispositivo.
