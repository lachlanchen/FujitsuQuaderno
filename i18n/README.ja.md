# Fujitsu Quaderno

*Fujitsu Quaderno Digital Paper デバイス向けの調査メモと軽量ツールです。*

このリポジトリは、世代ごとのモデル整理、ジェイルブレイクとファームウェア
調査、Fujitsu 公式ファームウェアリンク、文書管理用ツールをまとめます。
現在のローカル対象は Quaderno A4 Gen 2 `FMVDP41` で、root や ADB ではなく、
ペアリング済みの通常 Digital Paper API で操作しています。

## 内容

- `research.md`: 世代マップ、関連リポジトリ、ローカル制御メモ。
- `firmware-download-links.md`: 公式ファームウェアパッケージ。
- `tools/README.md`: macOS マウントランチャーのメモ。
- `tools/quaderno-mount.sh`: 軽量マウント補助スクリプト。
