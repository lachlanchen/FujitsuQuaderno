# Fujitsu Quaderno

*面向 Fujitsu Quaderno Digital Paper 设备的研究笔记和轻量工具。*

本仓库整理 Quaderno 各代型号、越狱与固件研究、Fujitsu 官方固件链接，以及实用
的文档管理工具。当前本地设备上下文是 Quaderno A4 Gen 2 `FMVDP41`，通过已配对
的普通 Digital Paper API 控制，而不是 root 或 ADB。

## 内容

- `research.md`：代际映射、相关仓库和本地控制记录。
- `firmware-download-links.md`：官方固件包链接。
- `tools/README.md`：macOS 挂载启动器说明。
- `tools/quaderno-mount.sh`：轻量挂载辅助脚本。
