# Fujitsu Quaderno

*面向 Fujitsu Quaderno Digital Paper 裝置的研究筆記與輕量工具。*

本倉庫整理 Quaderno 各代型號、越獄與韌體研究、Fujitsu 官方韌體連結，以及實用
的文件管理工具。當前本機裝置是 Quaderno A4 Gen 2 `FMVDP41`，透過已配對的普通
Digital Paper API 控制，而不是 root 或 ADB。

## 內容

- `research.md`：世代對照、相關倉庫與本機控制記錄。
- `firmware-download-links.md`：官方韌體套件連結。
- `tools/README.md`：macOS 掛載啟動器說明。
- `tools/quaderno-mount.sh`：輕量掛載輔助腳本。
